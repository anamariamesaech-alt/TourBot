
**Nombre del proyecto:** TourBot Colombia.

**Descripción:** Chatbot turístico desarrollado en Python e integrado con Telegram. Permite identificar lugares turísticos de Colombia mediante fotografías y consultar información sobre historia, atractivos turísticos, gastronomía, actividades, hospedaje y transporte.

**Repositorio de GitHub:** https://github.com/anamariamesaech-alt/TourBot
